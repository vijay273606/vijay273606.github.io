# Portfolio Website -- SPEC.md

## Sections
- About: two short paragraphs based only on supplied resume or content notes, not invented.
- Projects: title, one-line description, and link for each project listed in content/projects.md.
- Contact: email or LinkedIn link only. No contact form.

## Visual constraints
- Single-page website.
- Clean professional layout.
- Must look acceptable on desktop and mobile.
- Avoid flashy animation.
- Use readable fonts and good spacing.

## Privacy constraints
- Do not publish resume.pdf.
- Do not include phone number, full address, personal IDs, or sensitive personal data.
- Do not copy any file from private/ into the public website.

## Deployment
- Static website suitable for GitHub Pages.
- Main file should be index.html at repository root unless there is a clear reason otherwise.

## Acceptance criteria
- Website opens locally without errors.
- About section uses only provided facts.
- Projects section contains only projects listed in content/projects.md.
- No private/ file is referenced from the website.
- The page is usable on a mobile-width screen.
- All links included in the page are valid or clearly marked as placeholders.
