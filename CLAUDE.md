# CLAUDE.md -- Project Memory

## Project
This is Section 3.4.2 practice for the IISc Agentic AI Coding course: Build 2, Adding Context.

## Stack
Static website using HTML, CSS, and optionally simple JavaScript.

## File layout
- index.html: main page
- styles.css: styling
- content/projects.md: project facts
- private/resume.pdf: local-only source material, not to be published
- assets/: public images only, if needed

## Rules for the agent
- Read SPEC.md before planning or editing.
- Do not invent biographical facts.
- Do not publish or copy private/resume.pdf.
- Do not include personal phone number, full address, or private details.
- Before writing files, summarize the plan and assumptions.
- After writing files, explain what changed and how to preview locally.

## Deployment convention
The site should be deployable using GitHub Pages from the main branch and repository root.
